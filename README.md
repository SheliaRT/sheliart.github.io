# sheliart.github.io

Personal research website of Shelia Rahman Tuly — live at https://sheliart.github.io

Plain HTML/CSS, no build step.

- `index.html` — all content (about, news, publications, projects, experience, education)
- `style.css` — styles (light/dark theme tokens at the top)
- `assets/photo.jpg`, `assets/SheliaCV.pdf` — profile photo and CV

To update: edit `index.html` (e.g. add a `<li>` under News or Publications), replace `assets/SheliaCV.pdf` for a new CV, then commit and push to `main`.
